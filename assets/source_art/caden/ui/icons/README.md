# Caden UI Icon Source Art

`caden_ui_icons_cursors_input_prompts_batch_b_master_v2.png` is the immutable supplied Batch B presentation sheet. Its filename and bytes are preserved exactly.

It is not a runtime atlas. The source is RGB, contains a baked checkerboard and soft edge pixels, and does not define equal extraction cells. Only the small, reviewed subset recorded in `assets/ui/caden/caden_ui_runtime_manifest_v1.json` is approved for runtime v1. All other examples remain excluded unless they receive their own size and alpha review.

The runtime brief also names `caden_ui_icons_keycaps_master_v1.png`; that canonical file was not supplied, so no differently versioned alias was fabricated. Blank keycap states were instead prepared from the reviewed blank-frame row in this supplied master, with every input letter remaining dynamic Godot text.
