# Caden Modular Environment Expansion Library v1

This directory preserves the supplied modular environment expansion as immutable source art for future Caden environment work.

## Library contents

- `source_masters/` — five original RGBA sheets, each containing 36 candidates.
- `metadata/ASSET_CATALOG.md` — the supplied 180-ID human-readable catalog.
- `audit/AUDIT_SUMMARY.md` — the supplied source-master quality audit.
- `PROVENANCE_AND_USAGE.md` — the supplied provenance and usage record.
- `PACKAGE_README.md` — the unmodified README from the source archive.
- `SHA256SUMS.txt` — hashes for every unmodified file imported from the archive.

## Integration status

All 180 entries remain `SOURCE_CANDIDATE_CLEANUP_REQUIRED`. The sheets are not runtime atlases, and no candidate in this directory is approved for direct scene use. Runtime extraction, cleanup, normalization, collision, depth sorting, placement, and approval remain separate work.

The archive's embedded integration prompt was reviewed as attachment content but was intentionally excluded from this source-art library. This import does not change any scene, runtime manifest, gameplay geometry, collision, or approval state.
